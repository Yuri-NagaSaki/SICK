NETSNetwork Endpoint Throughput Sampler

How fast is this link, really?

NETS runs iperf3 send and receive tests, over IPv4 and IPv6, against 23 curated public endpoints in North America, Europe and Asia-Pacific — Leaseweb, Clouvider, Eranium, Wobcom, Scaleway and more. It only needs iperf3.

$curl -sL https://ba.sh/nets | bash

All 23 endpoints, both directions, 10 s each — moves a lot of data.

  • iperf3 only
  • IPv4 · IPv6
  • NA · EU · APAC

Recipes

Examples

$curl -sL https://ba.sh/nets | bash -s -- -r -t 5

Reduced set, 5 s per direction — a good first look.

$curl -sL https://ba.sh/nets | bash -s -- --region apac -4

Asia-Pacific endpoints, IPv4 only.

$curl -sL https://ba.sh/nets | bash -s -- --region eu --recv-only -t 8

Europe, download only — about half the traffic.

$curl -sL https://ba.sh/nets | bash -s -- -y -r

Install iperf3 if it's missing, then run the reduced set.

$curl -sL https://ba.sh/nets | bash -s -- -l

Print the endpoint catalog without testing.

$curl -sL https://ba.sh/nets | bash -s -- -r --json > nets.json

JSON results; the live progress still shows on stderr.

$curl -sL https://ba.sh/menu | bash -s -- nets -r

Through the launcher menu.

Notes

Good to know

Why does an endpoint say “busy”?

Public iperf3 servers run one test at a time. NETS tries other ports in the endpoint's range, then moves on. Busy is normal and says nothing about your server — the numbers are comparative, not lab-grade capacity.

How much traffic does a run use?

The summary totals what was actually sent and received. As a rule of thumb, one 10-second test at 1 Gbps moves about 1.25 GB — a full dual-stack run covers 23 endpoints in both directions, so on metered servers start with -r, --region or --recv-only.

What does it need?

Only iperf3 — the catalog and results are parsed with awk, no python3. If iperf3 is missing NETS asks Y/N before installing it (-y installs without asking, --no-install exits instead), and afterwards offers to remove it again (--cleanup / --keep-packages decide up front).

What happens with a dead endpoint, or when I press Ctrl-C?

Timeouts, refusals and DNS failures are recognised and skipped quickly instead of retried port by port. A live status line shows the test in progress; Ctrl-C stops and prints a summary of what finished.

IPv4, IPv6 or both?

NETS probes both families first and tests every one that works; endpoints without an IPv6 address show “no IPv6”. Use -4 or -6 to limit the run to one.
