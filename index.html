Tools

Three scripts, one habit.

Each one runs straight from curl, prints a report you can read at a glance, and doesn't stick around.

SICKServer Info & Check Kit

Hardware, inventoried.

A one-shot report of everything in the box — colorized tables or JSON.

  • CPU, NUMA, virtualization, temperatures
  • Memory per DIMM: size, speed, vendor, part
  • Disks & SMART, NVMe wear, RAID / HBA
  • NICs, GPU, motherboard & BIOS
curl -sL https://ba.sh/sick | bash

NETSNetwork Endpoint Throughput Sampler

Throughput, measured.

Public iperf3 send and receive tests against curated endpoints worldwide.

  • 23 endpoints across NA · EU · APAC
  • IPv4 and IPv6, Mbps / Gbps
  • Quick 8-node pass with -r
  • Traffic used is totalled at the end
curl -sL https://ba.sh/nets | bash
NETS docs
CPUXCPU eXaminer

Scores that actually print.

Geekbench 5, 6 and 7 — run one after another, scores read back into your terminal.

  • Single- and multi-core, never swapped
  • x86_64, ARM64 and RISC-V builds
  • Binaries removed afterwards
  • Re-fetch later with --fetch URL
curl -sL https://ba.sh/cpux | bash

Launcher

Or run all of it at once.

curl -sL https://ba.sh/menu | bash opens a small menu: 1 SICK · 2 NETS · 3 CPUX · 4 all · 0 exit. all is the full check, yabs-style — SICK → NETS (reduced) → CPUX (Geekbench 6) in one scrollback.

Through curl | bash, put arguments after bash -s --. Without an interactive terminal the menu prints its usage and exits instead of hanging.

$curl -sL https://ba.sh/menu | bash -s -- all

Full check: SICK → NETS (reduced) → CPUX (Geekbench 6).

$curl -sL https://ba.sh/menu | bash -s -- all -cn

The same, with Chinese output.

$curl -sL https://ba.sh/menu | bash -s -- sick -cn

Jump straight to one tool and pass its options.

$curl -sL https://ba.sh/menu | bash -s -- nets -r -t 5

NETS, reduced set, 5 s per direction.

$curl -sL https://ba.sh/menu | bash -s -- nets -y --region eu

NETS in Europe; install iperf3 without asking.

$curl -sL https://ba.sh/menu | bash -s -- cpux all

Geekbench 5 → 6 → 7.

Why Catbash

Made for the box you just logged into.

Zero footprint

No installer, no daemon. Missing tools are installed only if you say yes — and removed again with --cleanup. Temp files and Geekbench binaries are deleted afterwards.

Pipe-safe

Built for curl | bash. Without a TTY — ssh host '…', cron, CI — nothing waits on a prompt that can't be answered.

JSON when you need it

--json puts a machine-readable result on stdout; progress goes to stderr.

English & 中文

SICK, CPUX and the all run speak Chinese with -cn, with columns that stay aligned.

Read before you run

Every tool is a single plain bash file with no binaries and no obfuscation — the same file the short link serves. Page through it before you pipe it into a root shell:

$curl -sL https://ba.sh/sick | less
