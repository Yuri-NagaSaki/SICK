CPUXCPU eXaminer

CPU scores that actually print.

CPUX runs Geekbench 5, 6 and 7 on Linux — x86_64, ARM64 or RISC-V — one version or all of them, strictly one after another, and reads the single-core and multi-core scores back into your terminal. Downloaded binaries are removed afterwards.

$curl -sL https://ba.sh/cpux | bash

Interactive: 1 GB5 · 2 GB6 · 3 GB7 · 4 all. Without a terminal it runs Geekbench 6.

  • GB5 · GB6 · GB7
  • single + multi core
  • x86_64 · ARM64 · RISC-V

How scores are read back

The tryout CLI never prints scores. CPUX does.

Geekbench's tryout mode uploads results to the Geekbench Browser but leaves the terminal blank. Scripts that scrape the result page get empty — or swapped — columns when Cloudflare steps in. CPUX asks a bounded chain of sources, first complete answer wins, within --fetch-timeout (120 s).

Every number is paired with its own “Single-Core / Multi-Core Score” label, so the two can never be swapped. If all sources fail, you get a one-line --fetch retry command.

  1. Local CLI outputLicensed builds print a summary themselves.
  2. The result pagebrowser.geekbench.com directly — plain, then browser user agent, over IPv4.
  3. Raw result JSON<url>.gbN when it's public (needs python3 or jq).
  4. catbash.net/api/gbA server-side fetch on Cloudflare (worker.js), cached once found.
  5. r.jina.aiA reader proxy, with the cache bypassed.

Examples

Geekbench 6 only — the usual VPS comparison.

$curl -sL https://ba.sh/cpux | bash -s -- --fetch https://browser.geekbench.com/v6/cpu/123456

Scores missing? Fetch them later for an existing result — no re-run.

Through the launcher menu.

Notes

Good to know

What does it need?

Outbound HTTPS over IPv4 to cdn.geekbench.com and browser.geekbench.com, curl or wget, and tar. Each build is a large download (roughly 200–400 MB unpacked); CPUX looks for a work directory with about 600 MB free and prefers disk over tmpfs.

Will it hurt my server?

Geekbench loads every core for minutes per suite. Run it on a host that can take full CPU load — not on a production box that freezes under pressure. CPUX warns when memory is under about 1 GiB or the machine is already busy, because both drag scores down.

The scores are missing — what now?

Fresh result pages can take a minute to appear, and some networks get challenged by Cloudflare. CPUX keeps trying for up to 120 seconds, then prints a one-line --fetch command: run it later to read the scores without benchmarking again.

Where do the claim link and binaries go?

The claim link is printed and appended to ./geekbench_claim.url, so you can add the result to your Geekbench account. Unpacked builds are deleted after each suite unless you pass -k.

Where else can I get the script?

https://ba.sh/cpux and https://catbash.net/cpux serve the same file; https://raw.githubusercontent.com/Yuri-NagaSaki/SICK/main/cpux.sh is the GitHub fallback.
